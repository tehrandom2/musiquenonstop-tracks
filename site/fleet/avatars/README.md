# Fleet avatars

Every file here is a plain initials placeholder (512 px), at the same path as before so callers keep working.

The rule for every surface: a portrait is shown only if its stem is on the allowlist in the fleet repo,
`art/advanced-studios-avatars-original-v1/APPROVED.json` (`{"approved": [stems]}`), and the portrait is the original
painted beside it (`<stem>.png`), reviewed by the game director. Any stem not on the list stays initials.
When a stem is approved, copy its reviewed original over the placeholder here and publish.
